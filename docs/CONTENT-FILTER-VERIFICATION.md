对源目录全部文件在验证前后计算 SHA-256，均保持一致。保留记录的压缩字节、光照和时间戳原样复制，
解析失败会终止核查。索引判断实际使用的调色板条目，不根据 Status、InhabitedTime 或仅凭调色板名称判断建筑。

浏览器端仅点击「分析地图」，服务端正式转换状态仍为 idle，源预览已达到 done 并显示地图；

贴图 JAR 已缓存、地图没有既有渲染瓦片时，BlueMap 源渲染进程约 8.96 秒，结果渲染进程约 5.85 秒。
这是单次本机测量，统计的是 render.log 创建至最后写入的时间，不包括下载资源、内容核查及浏览器加载，
不应宣称为所有地图的首次启动总耗时。

Gradle 离线运行 `:cli:test :cli:shadowJar` 成功，4,182 个测试、0 失败。新增测试覆盖未使用的调色板条目、
三种空气、无效索引、旧版高位 ID、悬挂实体、邻区保留、缓存失效、原图不变和旧柱必须写空。
前端两段脚本通过语法检查；浏览器预览无错误日志。
