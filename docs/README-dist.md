# 地图降级转换工具

把高版本 Minecraft 存档（1.13 及以上）转换为可在 **1.12.2** 打开的存档，
并在网页里**左右对比转换前后的 3D 外观**。

## 运行

需要 **Java 21 或更高版本**（如果用的是带 `runtime/` 的完整包，则不需要装 Java）。

双击 `启动.bat`，或在命令行执行：

```
java -jar chunker-cli-1.20.0.jar
```

浏览器会自动打开界面（默认 `http://localhost:8123/`）。关闭命令行窗口即退出。

## 怎么用

1. **选地图**：点「自动查找我电脑上的存档」直接选，或点「选择文件夹…」弹框选，
   也可以直接把路径填进输入框。地图文件夹里应该有 `level.dat`。
2. **先分析（推荐）**：点「先分析会丢失什么」，几秒内告诉你这张图里哪些方块会丢、
   哪些会被换成别的。**不会生成任何文件**。
3. **改映射（可选）**：分析出来的清单会填到「方块映射」里，按数量从多到少排序。
   不想让某个方块变成内置的替代物，就在那一行填你想要的。你写的规则优先于内置规则。
4. **开始转换**。完成后右侧自动显示左右对比。

## 选项

- **自动上移地图**：1.18 及以上的存档延伸到 Y=-64，而 1.12.2 只能到 0~255。
  勾选后整张地图上移使最低点落在 Y=0。1.13~1.17 的存档本来就在范围内，不会被挪动。
- **清空容器物品**：保留箱子、熔炉等方块外观，但不搬运里面的物品。
- **把 1.12.2 没有的方块换成最接近的**：关闭后这些方块直接变空气。

## 改映射后预览会自己更新

调一条映射重新转换，右侧预览会自己更新，**不用手动刷新**，通常几秒到几十秒。

因为内容没变的区块根本不会重写，只有真正变了的会被重新渲染。报告里会写明
「重新写入的区块: N 个（其余 M 个与上次完全相同，未重写）」。

## 转换规则（刻意的取舍）

这个工具是为了**搬运建筑外观**，不是完整复制世界，所以：

- 生物、掉落物等实体会被删除，**画和展示框保留**（它们是建筑的一部分）
- 箱子等容器保留方块本身，内部物品清空
- 1.12.2 没有的方块会换成最接近的（楼梯→楼梯、墙→墙，尽量保持形状）
- 超出 1.12.2 高度上限的部分会被裁掉

**所有被替换、删除、裁剪的内容都会写进报告**（`conversion-report.json` / `.txt`，
输出文件夹里也有一份）。转换本身不会告诉你哪里少了东西，报告是唯一能分辨
「本来就没有」和「转换丢了」的依据。

## 目录结构

```
├─ 启动.bat                    启动脚本
├─ chunker-cli-1.20.0.jar      主程序
├─ bluemap/
│  ├─ BlueMap-5.16-cli.jar     渲染「转换前」（支持 1.13.2–1.21.11）
│  └─ BlueMap-1.5.5-cli.jar    渲染「转换后」（支持 1.12.2–1.17）
├─ runtime/                    自带的 Java 运行时（有这个就不用装 Java）
└─ work/                       运行时生成
   ├─ converted/               转换结果
   └─ viewers/                 对比预览的工作文件
```

为什么需要两个 BlueMap：没有任何一个版本的 BlueMap 能同时渲染源地图和 1.12.2。
BlueMap 跟随游戏的数据格式，能读懂现代存档的版本已经删除了对 1.12.2 的支持
（1.6.3 更新说明写着「Dropped Minecraft 1.12.2 support」），
而能读 1.12.2 的版本又读不了现代存档。所以左用 5.16、右用 1.5.5。

## 命令行用法

不想开界面时：

```
java -jar chunker-cli-1.20.0.jar cli -i <源地图> -o <输出> -f JAVA_1_12_2 --shiftToFit
```

注意 **必须写 `cli`**。不写的话会启动网页界面（这是设计如此），脚本里调用时容易忘。

## 首次运行需要联网

第一次渲染对比图时，BlueMap 会从 Mojang 服务器下载对应版本的客户端资源（用于取方块贴图），
之后会缓存到 `work/viewers/`，不再重复下载。

## 已知限制

- 转换目标只有 1.12.2
- 尚未在真实的 1.12.2 客户端上做过加载测试（目前用 BlueMap 渲染作为验证手段）
- 高版本红石行为、命令方块内容不做降级
- 建筑若建在 Y=256 以上（1.18+ 世界高达 320），上移后仍会被裁掉，报告里会写明裁了多少
