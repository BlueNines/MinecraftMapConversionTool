## 新界面

采用深灰与薄荷绿的工具型界面，同时提供浅色主题。左侧只保留地图、输出与转换策略，中央分成三个工作区：

- **分析与映射**：欢迎页、分析摘要、完整映射表、搜索、分类筛选与分页。
- **对比预览**：左右、仅源地图、仅转换结果三种布局，可收起侧栏，也可在新窗口打开某一侧。
- **转换报告**：替换、丢失、高度与实体处理摘要，原始 JSON，输出路径复制和报告下载。

主要操作位于顶部，任务状态与进度位于固定底栏。主按钮按状态显示“选择地图”“分析地图”“开始转换”“应用并重新转换”。开始转换前展示确认信息。

欢迎页的等距建筑插图仅作装饰，不是实际地图预览。预览区没有地图时只显示空状态，不用示意图冒充转换结果。

## 交互与数据处理

1. 保留 `/api/resolve-dropped`：拖入后先按名称查找，唯一结果直接选中，同名多个由用户选择，找不到才打开系统选择框。
2. 映射输入即时写入草稿，不在输入时重建整张表；翻页和切换筛选不会丢掉其他行输入。
3. 每页 20 条，全部条目可以翻页查看，不再只显示前 40 条。
4. 按源地图保存最近 8 个项目的本地草稿；存储失败时提示仅当前页面保留。
5. 导入、导出兼容 `identifiers` JSON。导入先整体校验再修改，拒绝重复源键；文件限制 5 MB。
6. 自定义规则仅在重新转换时应用。报告和预览明确提示未应用修改，不把旧结果当成新配置的预测。
7. 合并报告中同种方块的多个状态记录，优先列出丢失项，再按数量排序。
8. 任务执行时锁定相关编辑操作；状态轮询串行执行，连接中断后退避重连，不自动重复提交转换请求。
9. 无百分比的阶段使用真正匹配 CSS 的不定进度动画。转换失败、渲染失败与未连接分别显示。
10. 预览失败时仍保留转换报告和输出信息，可以单独重新渲染；同目标的增量更新仍由原后端处理。
11. 增加键盘页签操作、焦点样式、输入标签和 reduced-motion 支持，适配窄窗口与手机宽度。

## 后端能力边界

- 当前 `/api/scan` 固定使用自动上移，且会写入、清理本地临时试转文件。因此界面不再称其“完全不写文件”；关闭自动上移时提醒以正式转换报告为准。
- 后端读取 `clearContainers` 后没有把它传入转换任务，本次取消了误导性的可选开关，明确告知容器内容会清空。
- 当前状态接口没有任务 ID、源目录与输出目录身份。重新打开页面接续任务时，明确标记“无法确认预览与当前草稿对应”，不伪造关联。
- 两侧 BlueMap 独立操作，尚未实现跨版本镜头同步；也没有后端任务取消接口，不放置无效按钮。
- 方块规则校验是标识符语法校验，不等于目标方块一定可在 1.12.2 写入；候选列表来自现有后端，最终转换结果仍须查看报告。
- 前端路径比较只是防误操作，不是文件系统安全边界。符号链接、路径别名及默认输出目录等最终应由后端进行规范路径校验。
- 草稿保存在浏览器 origin 下，切换工具端口可能产生另一套浏览器存储。

## 本轮执行的验证

对本次生成的完整 HTML 做了 JavaScript 语法检查，并在 Chromium 144 中执行 32 项浏览器测试，结果为 **32 通过、0 失败、0 错误**。最后一次测试耗时约 31.54 秒。

测试环境不允许 HTTP/file 导航，所以通过 `page.set_content` 渲染实际页面。网络请求由与已读取 Java 接口对应的模拟 API 响应；浏览器存储、下载捕获和 iframe 使用测试适配器。测试没有绕过环境导航限制。

因此，这些结果证明的是页面 DOM、交互和请求组织在模拟响应下的行为，**不是完整产品端到端验收**。它们不证明原生 localStorage、真实下载、操作系统文件夹选择器、Java 转换、BlueMap 渲染或 Minecraft 客户端加载已经通过。测试执行发生在会话工作环境中，本仓库目前只包含结果记录，不将其冒充为已接入 CI 的测试套件。

## 在真实环境验收

在干净工作树或单独克隆中切换到 `ui/map-workbench-redesign`，按原项目方式运行 `tools/build.ps1`，然后启动新构建的程序。只双击仓库 HTML 可以查看外观，但无法替代本地 Java API。

建议使用可丢弃的地图副本，依次验证：

- 系统文件夹选择、拖拽唯一/同名多结果、中文和带空格路径。
- 真实预分析、映射修改、关闭近似替换、首次转换与重复转换。
- 更换源地图或输出位置后，不保留错误的旧预览。
- 首次 BlueMap 渲染、渲染失败后重试、同目标增量更新。
- 页面刷新、程序重启和连接中断时的状态恢复。
- 原生浏览器草稿存储、JSON 文件下载、剪贴板权限与导入。
- 用原版 1.12.2 在备份副本上加载结果，检查关键建筑、楼梯朝向、展示框和高度裁剪。

本次未执行 Java 构建、真实地图转换、BlueMap 渲染及原版 1.12.2 加载验证。界面重构不改变这个发布边界。
