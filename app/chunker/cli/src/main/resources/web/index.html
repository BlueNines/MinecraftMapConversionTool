一个清晰的转换流程
01 选择地图与模式
先选择地图，再选择降级或无损模式，进入规则工作区。选择包含 level.dat 的地图文件夹。分析通过本地临时试转生成报告，同时独立渲染源地图 BlueMap。临时转换结果会清理，源预览缓存会保留；不是零磁盘写入。
02 调整映射
输入即保存本地草稿，筛选、翻页不会丢失输入。此浏览器保留最近 8 张地图的草稿。导入与导出兼容 identifiers JSON；修改不会自动开始转换。
03 转换并检查
转换后自动启动 BlueMap。可切换单侧或双侧，暂不支持同步镜头。保留原存档备份，再用 1.12.2 客户端检查。
现有后端限制
预分析固定按自动上移计算；取消上移时以正式转换报告为准。容器内容固定清空。当前服务没有取消任务接口。
