# 地图降级转换工具

把高版本 Minecraft Java 版存档（**1.13 及以上**）转换为可在 **1.12.2** 打开的存档，
并在网页里**左右对比转换前后的 3D 外观**。本地运行，打开即用。

它面向的场景是**搬运建筑外观**：保留建筑的形状、布局与视觉效果，而不是完整复制世界。
生物、掉落物、容器物品这些不属于「建筑外观」的东西会被丢掉，
被替换、删除、裁剪的内容**全部写进报告**。

## 功能

- **选地图**：拖入、弹选择框选、自动查找电脑上的存档，或直接填路径
- **先看看会丢什么**：不生成任何文件，几秒内列出这张图里哪些方块会被丢掉或替换
- **方块映射**：指定某个方块该换成什么。内置 275 条近似规则并允许逐条覆盖
- **Y 轴平移**：1.18+ 的存档延伸到 Y=-64，而 1.12.2 只到 0~255，整个地图会上移使其落入范围
- **转换报告**：改了什么、丢了多少个、裁了多少、实体删了多少，都有数
- **左右对比预览**：左边源地图，右边 1.12.2 结果，两个不同版本的 BlueMap 并排
- **改映射实时生效**：调一条映射重新转换，预览只重渲真正变了的区块，几秒到几十秒就更新

## 使用

1. 到 [Releases](../../releases) 下载最新版本，解压到任意目录
2. 双击 `启动.bat`（需要 **Java 21 或更高版本**）
3. 浏览器会自动打开界面（默认 `http://localhost:8123/`）

详细说明见 [`docs/USAGE.md`](docs/USAGE.md)。

## 从源码构建

```powershell
# 需要 JDK 21（只编译的话 17+ 即可，但打包运行时用 21）
$env:JAVA_HOME = "C:\path\to\jdk-21"
.\tools\build.ps1
```

构建脚本会依次完成：编译主程序、取回两个版本的 BlueMap、
用 jlink 裁出一份自带 Java 运行时、组装出完整的 `dist/` 目录。
全程不需要手工拷贝文件。

## 技术要点

**两个 BlueMap**。没有任何一个版本能同时渲染源地图和 1.12.2：能读懂现代存档的版本
（v5.16）已经删除了对 1.12.2 的支持，而能读 1.12.2 的版本（v1.5.5）又读不了现代存档。
所以左边用 5.16、右边用 1.5.5。

**增量热更新**。预览能跟着改映射实时更新，靠的是两件事：转换时区块内容没变就不重写
（保留原时间戳），以及 BlueMap 按每个区块自己的时间戳决定该重渲哪些。
为此必须保证「同样的输入得到同样的字节」——详见 [`docs/DESIGN.md`](docs/DESIGN.md)。

## 已知限制

- 目标版本只有 1.12.2
- 没有在真实的 1.12.2 客户端上做过加载测试（目前用 BlueMap 渲染作为验证手段）
- 高版本红石行为、命令方块内容不做降级
- 容器只保留方块外观，内部物品不搬运（这是刻意的）
